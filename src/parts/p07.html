PART 7

Mixing desks & show files

The brain of the system. Different on every job; recognisably the same underneath.

7.1 The channel strip — the unit of everything

Whatever the desk, whatever the decade, a channel does the same things in the same order. Learn this once and every console makes sense.

INPUT → GAIN/PAD → PHANTOM → POLARITY → HIGH-PASS → GATE ↓ FADER ← PAN ← COMPRESSOR ← EQ ↓ ROUTING → mix bus / groups / matrix ↓ AUX SENDS (pre- or post-fade)
Pad
A fixed attenuator (usually −20 dB) for very hot sources, before the preamp.
High-pass filter (HPF)
Removes everything below a set frequency. Use it constantly — §4.3.
Gate
Mutes the channel when the signal drops below a threshold. Cleans up drum bleed and open mics.
EQ
Tonal shaping. Typically 4-band parametric on a decent desk.
Compressor
Reduces dynamic range — quiet bits up relative to loud bits. See §16.4.
Pan
Position in the stereo image.
Fader
Level into the main mix.
Aux send
A separate feed to somewhere else — a wedge, an IEM, a reverb, a recording. Pre-fade ignores the fader (monitors); post-fade follows it (effects).
PFL / AFL
Pre/After Fade Listen — soloing a channel to your headphones without affecting the mix.
Mute
Off. The most under-used control in live sound — anything not in use should be muted.
Standard

Pre-fade for monitors, post-fade for effects. Nearly universal, and the reasoning is simple: the band's wedge mix shouldn't change when FOH pulls a fader, but a vocal's reverb should get quieter when the vocal does.

7.3 Digital console concepts

Layers / banks
A desk with 16 physical faders and 64 channels shows you them 16 at a time. The fader you're moving is not necessarily the channel you think — always check the layer.
Channel vs socket
The physical input socket and the console channel are separate things, connected by a patch. Socket 12 does not have to be channel 12. This is powerful and it's also the single biggest source of confusion for people coming from analogue.
DCA / VCA
A master fader that controls a group of channels' faders remotely, without the audio passing through it. Perfect for "all drums", "all vocals".
Group / subgroup
An actual audio bus that channels are routed into, so you can process them together (e.g. compress the whole drum kit).
Matrix
A mixer of mixes — takes your main mix and other buses and creates additional outputs. Used for delay stacks, fills, broadcast feeds, recording feeds, the foyer.
Scene / snapshot / cue
A stored state of the console you can recall. Essential in theatre and corporate; used more sparingly in live music.
Safe / recall scope
Settings excluded from scene recall, so recalling a scene doesn't undo your gain changes. Learn this before you use scenes in anger.
Show file
The whole console state, saved to internal storage or USB.
Watch it

Loading a show file changes the output patch. If you load an unfamiliar show while the PA is on, you can send a full-range signal to an HF driver, unmute something into a live IEM, or dump 0 dB of pink noise into a full room. Habit: mute the outputs / turn the amps down before you load anything, then bring it back up and check. Every time.

Also seen

[2026] Some newer digital consoles and standalone products (Waves eMotion LV1 with its automixer, among others) offer AI-assisted automixing — automatically adjusting gain-sharing between open mics to reduce bleed and rider fatigue on multi-mic speech jobs. Genuinely useful on the right corporate/panel job with a competent operator supervising it. It is not yet, and shouldn't be treated as, a substitute for understanding gain structure and bleed control yourself — you still need to recognise when it's getting it wrong.

7.4 Show file discipline

  1. Save early, save often, save under a new name. Not show.scn repeatedly — ClientName_2026-08-25_v3.scn.
  2. Back up to USB at the end of every build and before any big change. Console internal storage fails.
  3. Take your own copy at the end of the job if it's yours to keep. Rebuilding a show from scratch because the file was on the hire desk that went out again is a bad afternoon.
  4. Start from a known base. Keep a clean template show for your common console — inputs named sensibly, HPFs in, standard routing, monitors on pre-fade. Loading that takes 30 seconds and saves 40 minutes.
  5. Name your channels. Not optional. An unnamed desk at line check is chaos, and if you get pulled away someone else has to be able to take over.
Standard

Naming convention that works: source first, position second. Vox Lead, Vox BV SL, Gtr Amp SR, Kick In, Laptop L. Keep it short enough to read in the console's tiny scribble strip.

Go deeper

On bigger or higher-stakes shows, the show file discipline above is only half the protection — the other half is console redundancy: a second, identical console mirroring the primary in real time (most modern digital desks support this natively) so a hardware failure on the main console is a seamless changeover rather than a dead PA. A cut-down version of the same idea, within reach on smaller shows, is a hot-spare — a second console loaded with the same show file, powered and patched, ready to swap to manually if the primary dies. Neither replaces the habit of saving and backing up; the show file is what a spare console actually runs.

7.5 Dynamics & EQ on the desk

Gate
Threshold (level to open), range/depth (how much it attenuates when closed), attack (how fast it opens), hold and release (how it closes). Used on toms and to control bleed.
Compressor
Threshold (where it starts working), ratio (how hard), attack (how fast it grabs), release (how fast it lets go), knee (how gradually it engages), makeup gain (to restore level).
Limiter
A compressor with a very high ratio, used to stop signals exceeding a ceiling. On outputs, protective. On IEMs, essential.
Parametric EQ (PEQ)
Choose frequency, gain and Q (bandwidth). Surgical. Your main tool.
Graphic EQ (GEQ)
Fixed bands, usually 31. Fast and visual. Traditional on monitors and system outputs.
Shelf
Boosts or cuts everything above (high shelf) or below (low shelf) a point.
RTA
Real Time Analyser — shows you the frequency content. Useful for identifying feedback frequencies fast. Not a substitute for ears.
Standard

Starting compressor settings for a live vocal: ratio around 3:1, medium attack, medium-fast release, threshold set so you're seeing 3–6 dB of gain reduction on the loudest phrases and none on the quiet ones. Then adjust by ear. Compression on live vocals is mostly about consistency, not effect.

7.6 Talkback, tone and solo

  • Talkback — a mic at the desk that can be routed to monitors, comms, or the stage. Check where yours is routed before you press it. Watch it Talkback accidentally routed to the main PA is a classic and very public mistake.
  • Oscillator / pink noise generator — built-in test signal. Invaluable for proving outputs. Sine wave for finding a specific driver, pink noise for general checks.
  • Solo modes — PFL (pre-fade, hear it regardless of fader position, standard for line checking), AFL (after fade), and Solo In Place (SIP), which mutes everything else in the actual mix.
Watch it

Solo In Place silences the PA for everyone. On desks where it's available, it should be disabled or locked during a show. If you press it by accident in front of an audience, everything except one channel vanishes. Know where that button is so you can avoid it.

The words you'll hear on a DM7

Rio / Tio stage boxes
Yamaha's Dante stage boxes. The DM7 works with first- and second-generation R-series Rio boxes and controls their preamps (HA remote) over Dante. Other Dante devices can be "mounted" so their inputs show up for patching.
HA
Head amp — the preamp gain. On a Rio it's the stage box's gain, controlled from the desk.
Selected channel
Press a channel's SEL key and its whole strip opens on the screen above that bay. On the full DM7 each bay can have its own selected channel (unlink the SEL keys in Setup → User Setup → Surface) — most engineers prefer that.
Sends on Fader (SoF)
Flips the faders to show every channel's send to one mix — the quickest way to build a monitor mix.
User Defined Keys (UDK)
Four banks of twelve touch keys on the 7" screen, set up for whatever the engineer wants one press away: talkback, mute groups, a mix, a scene.
Recall Safe / Focus Recall
Recall Safe protects chosen channels or parameters from every scene recall. Focus Recall sets, per scene, what that scene is allowed to change. Both explain most "a scene changed my channel" surprises.
Assist
Built-in helpers that suggest head-amp gains, channel names and a starting fader balance from what they hear. A starting point — the engineer still decides.
Split mode
Splits the full DM7 into two independent consoles (for example FOH and monitors, or two rooms) in one frame.
Dugan automixer
Built-in automatic mixing for speech mics — invaluable on panels and conferences (§10.11).
Watch it

On a shared Dante network a DM7 can see and control other people's Rio preamps. Never change HA gain, phantom or patching on a stage box you don't own — on a shared FOH/monitor system, one person's gain change moves everyone's levels. Ask who owns the preamps before the job.

Standard

Keep the console on current firmware (Yamaha publishes updates and release notes on its DM7 support pages), and check the show file was made on the same or older firmware before you load it. Learn it for free on the DM7 Editor (§8.1) and Yamaha's DM7 training videos.

7.9 DM7 — setting up a show, start to finish

The order below works whether you're building a show from scratch or loading an engineer's file. If the engineer is bringing their own file, your job is steps 1–4 and 9–11; theirs is the mix.

  1. Power and network first. Desk and stage boxes powered; Dante primary cables connected (secondary only to a separate secondary network, never to the primary switch — §8.9).
  2. Save what's on the desk before you touch anything. Store the current show file to USB with the date and job in its name.
  3. Load or initialise. Load the show file for this job (check firmware compatibility), or start from the initial data if you're building from scratch.
  4. Check Dante. In the Dante setup screen, confirm the desk sees every Rio or Dante device it should, the sample rate matches (48 or 96 kHz everywhere), and the clock leader is the one the design expects.
  5. Patch inputs. Input patch from the Rio (or local) inputs to channels, following the patch list. Name and colour each channel as you go.
  6. Patch outputs. Mixes, matrices and stereo to the right Dante or local outputs — PA feeds, sub feed, fills, monitors, recording, broadcast.
  7. Set up mixes. Monitor mixes pre-fade; effects sends post-fade (§7.1). Use Sends on Fader to build them quickly.
  8. Protect what must not change. Recall Safe on anything a scene must never touch (talkback, PA feeds, broadcast feed); Focus Recall on scenes that should only change some things.
  9. Line check every input (§11.3) and send tone or pink noise to every output at low level to prove the patch.
  10. Store a scene once the line check is clean, and save the show file to USB again.
  11. Write down anything that differs from the plan, for the engineer and for the derig.

7.11 DiGiCo — quick start for a first time on one

DiGiCo (SD9, SD10, SD12, Quantum 225/338/7) works differently from Yamaha and Allen & Heath, so do your homework on the free offline software before the job.

Session
The whole show: channels, I/O, routing, console setup. Think “one band”. Loading a session replaces everything — save the current one first.
Snapshot
Changes values within the session — think “one song”. It can't add channels or change the console's structure; that's a session's job.
Recall scope
What each snapshot is allowed to change. The classic trap: something isn't in the scope (head-amp gains, for example), so it doesn't change when you expect — or something is, and it changes when you don't. Check the scope before trusting a snapshot.
Macros
One-button actions the engineer sets up — save session, tap delay, mute groups. Ask before running one you didn't make.
  1. Save the current session (with the date) before you touch anything.
  2. Load the job's session; check the I/O (stage racks, MADI/Optocore/Dante) is seen and synced.
  3. Patch inputs and outputs from the input list; name and colour channels.
  4. Line check, then save the session again.
  5. If you're using snapshots, keep them simple: one complete snapshot per band, and check the recall scope on each.
Sources · checked Nov 2026

DiGiCo offline software tutorials and digico.tv training; engineer guidance on sessions, snapshots and recall scope (Sound Design Live; r/livesound, 2025–26). Menus vary by console and software version.

7.12 Allen & Heath dLive and Avantis — quick start

dLive splits the system in two: the MixRack holds the processing and most of the I/O; the Surface is the control desk. Avantis is a single self-contained desk that takes the same family of stage boxes. Both have free offline software (dLive Director, Avantis Director).

Socket names
R-nn = a MixRack socket, S-nn = a Surface socket, DX = an expander, P = an I/O Port card (Dante, MADI…), USB, FX, SigGen. Any socket can patch to any channel.
Scenes & Recall Filters
A Recall Filter stops a scene changing chosen channels or parameters — it belongs to that one scene. Global filters / safes protect things from every scene.
Show files
Saved to USB from the Surface (on dLive surfaces the data USB port, not the recording one).
SLink / DX / I/O Port
How stage boxes and network cards connect: SLink to GX, DX, AB and AR expanders; I/O Port cards for Dante, MADI and others.
  1. Save the current show file to USB first.
  2. Recall the job's show; check every expander and I/O card is connected and synced.
  3. Patch sockets to channels (I/O screen), set preamp gain, pad and 48V — only on preamps that are yours.
  4. Patch mixes to outputs; set recall filters and safes so scenes can't change what they shouldn't.
  5. Line check, store a scene, save the show to USB again.
